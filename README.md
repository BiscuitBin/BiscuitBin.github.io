# BiscuitBin.github.io

The BiscuitBin organisation landing page, published by GitHub Pages from
`site/` at https://biscuitbin.github.io/.

Links to project sites are relative (`pachinko/`, not `/pachinko/` or a full
URL), so they keep working when the org site moves to a custom domain.

Do not add a `CNAME` file. The custom domain is set in the repository's Pages
settings once `biscuitsbin.com` is verified for the organisation.
